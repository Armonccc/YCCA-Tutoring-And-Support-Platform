# YCCA Online Tutoring & Mentorship Platform – Project Management

## Overview
This repository contains a comprehensive project management plan developed as a group project for educational purposes. The project proposes an online tutoring and mentorship platform for the Youth Connect Center Association (YCCA), a non-profit organization supporting youth.

The platform aims to improve accessibility to academic support, mentorship, and digital resources by removing barriers such as transportation and scheduling.

This repository focuses on project planning and management rather than application development.

---

## Project Objectives
- Design a feasible online tutoring and mentorship platform
- Improve youth access to academic and career support
- Create a mentor–youth matching system
- Develop scheduling, messaging, and resource-sharing concepts
- Apply PMBOK-aligned project management practices
